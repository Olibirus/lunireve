# Image prompts — the 7 personality archetypes (character wizard, step 4)

Cards on `/compte/personnages/nouveau`, step 4 "Personnalité". Each card is a
**square** picture with the title and its 3 traits underneath.

## How to use

1. Generate each image with the prompt below.
2. Save it with the EXACT filename given, as **WebP, 1:1 square**, 800x800 or
   larger (they render at ~200px, so anything above 600px is plenty).
3. Drop it in `app/public/illustrations/`.
4. Nothing else to do: the cards already point at
   `/illustrations/archetype-<id>.webp` and show the art the moment the file is
   there. Until then the emoji stands in.

**Style:** not described on purpose. Run these through Nano Banana with your
Lunireve logo as the style reference so all 7 match the brand fox.

**Consistency rules (important, the 7 sit side by side):**
- Same fox character every time: the Lunireve fox cub, cream-and-ginger coat.
- Same framing: fox centred, full body or three-quarter, filling most of the
  square, generous margin, simple uncluttered background.
- Only the pose, expression and one or two props change between the 7.
- Gender-neutral throughout: no bows, no eyelashes, no skirts, nothing that
  reads as "girl fox" or "boy fox".
- No text, letters, numbers or logos anywhere in the image.
